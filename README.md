# running-calculator 🏃

Консольный калькулятор на Python для расчёта среднего темпа и скорости бега в километрах и милях.

## Возможности программы
* **Двойной расчёт:** вычисляет общее время в секундах, средний темп и среднюю скорость одновременно в километрах (мин/км, км/ч) и в милях (мин/милю, миль/ч).
* **Удобный ввод:** поддерживает целые числа, а также дробные значения как через точку (`2.5`), так и через запятую (`2,5`).
* **Защита от ошибок:** перехватывает случайный ввод текста, не допускает деления на ноль и просит повторить ввод при опечатке.

## Как запустить
1. Скачайте файл `speed.py`.
2. Откройте терминал в папке с файлом и выполните команду:
```bash
python speed.py
```
