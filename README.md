# running-calculator 🏃

Консольный калькулятор на Python для расчёта среднего темпа и скорости бега.

## Возможности программы
* **Расчёт показателей:** вычисляет общее время в секундах, средний темп(мин/км) и среднюю скорость (км/ч).
* **Удобный ввод:** поддерживает целые числа, а также дробные значения как через точку (`2.5`), так и через запятую (`2,5`).
* **Защита от ошибок:** перехватывает случайный ввод текста, не допускает деления на ноль и просит повторить ввод при опечатке.

## Как запустить
1. Скачайте файл `speed.py`.
2. Откройте терминал в папке с файлом и выполните команду:
```bash
python speed.py
```

## Пример работы
```text
Введите дистанцию (в км): 3
Сколько минут заняла пробежка: 20
Сколько ещё секунд: 12

--- Итоги пробежки ---
Общее время:       1212 сек
Средний темп:      6 мин 44 сек на 1 км
Средняя скорость:  8.91 км/ч
```
